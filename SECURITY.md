# Security & child privacy

This is a static catalog of offline-capable games, with no server component, accounts, ads, player tracking, form submission, or network APIs. Do not add those features without a deliberate security/privacy review.

Keep each playable game entirely self-contained. Avoid remote scripts or assets, unsafe HTML injection, sensitive data storage, and links that unnecessarily disclose player activity. Do not publish minors' private details beyond names explicitly approved for public credit.

To report a potential security issue, use GitHub's private vulnerability reporting feature if enabled on the public repository. If not enabled, contact the repository owner privately; do not post exploitable details in public issues.
